# HUD 光学质量分析台

直接用 Edge / Chrome 打开 `HUD分析工具.html`。单文件包含解析器、图表及本次提供的 15 件样品示例，可离线使用，不上传数据。共享此文件也会共享内置示例数据。

## 使用

1. 点击“查看本次表格”查看 L232 示例，或“导入 Excel”读取同结构 `.xlsx` / `.xls`。
2. 切换眼位、搜索项目、查看趋势图或分布图。每个点悬停显示样品编号和数值。
3. 核对客户限值。可逐项修改上下限，留空表示该侧不设限。“应用”后重新统计。
4. 导出单项 PNG / SVG、所有项目汇总 CSV；“保存交互报告”保留数据和修改后的限值，可独立离线打开并继续筛选。报告不支持重新导入，重新导入请打开工具。
5. 打印 / PDF 使用当前筛选结果。导出图表不包含完整判定说明，交付客户时建议同时提供报告及限值依据。

## 输入与统计

首行首列为 Item，之后为样品编号；每行一个测量项目。空白、非数值单元格不计入统计，卡片列出数量。没有任何数值的行不生成项目。表内顺序作为横轴，不能据此推断时间顺序。标准差为样本标准差（n−1）。限值边界算限值内，未设置上下限则不计算合格率。汇总中的样品数为不同编号数量，未推断跨眼位的实际玻璃对应关系。

当前 Excel：EB_N 15 项、EB_H 17 项、EB_L 17 项，每项 15 个数值；共 735 个测量值。预留至 500 的空白列不计入。19 项有默认限值，30 项待补限值。

## 默认限值及适用范围

- 工作表声明的重影范围：EB_N ±1 mm，EB_H / EB_L ±1.5 mm。仅按工作表进行双向筛查，不直接等同于原 PDF 的方向性要求。原 PDF 中高眼位向下、低眼位向上；项目最终批准值优先。水平重影的具体适用性也应由客户确认。
- Rotation_Avg：±1°。平均值不能代替规范规定的各水平线段旋转检查。
- Image Size：−5% 至 +5%。现有全局数据不能代替所有相邻网格点的验证。
- Global Mag：以 100% 为标称，95% 至 105%，按工作表将其列入 ±5% 的说明推定，须核对客户指标定义。
- Translation、Distortion、Trapezoid 没有默认限值；仅出图和统计，不自动判合格。
- 本工具不声称整片玻璃通过 CG3552，不计算缺少原始逐点数据的最终三眼位重影判定。

## 开发与验证

源码入口 `index.html`，统计逻辑 `core.js`，界面 `app.js`。使用已存在的 checkout；不需要新建 worktree。无构建依赖：运行 `python build.py` 生成单文件工具；`node test.cjs` 验证解析与统计逻辑。可用 `python -m http.server 8765` 在本机测试，或直接打开单文件。

Excel 解析使用 SheetJS CE 0.18.5，Apache-2.0，许可证在 vendor/LICENSE-xlsx.txt。图表使用内置 SVG，无外部服务。
